Agentic Trip Planner Task 11

One goal in, a multi-step AI agent out: it plans, calls 6 tools, keeps state, recovers from errors and asks a human before booking.

Instant demo
Mission Control

“Plan a 3-day trip to Goa for 2 people under Rs 15,000 and book the hotel.”

The agent turns that one sentence into a plan, runs it step by step (Thought → Action → Observation), re-plans when the budget breaks, survives a dead weather API, and pauses for your approval before it spends money.

Runs locally · Qwen2.5-0.5B on CPU · no API keys · sample hotel & attraction data

        Limitations

        • Small local model (Qwen2.5-0.5B, CPU): it extracts the goal well, but its plans and numbers are checked by rules and a fixed fallback plan is used when it slips.
        • Hotels and attractions are sample data (10 Indian cities). Bookings are written to a local JSON file, so no real money moves.
        • Weather is live (Open-Meteo); the fallback is a typical-climate table, not a real forecast.
        • One room per booking, fixed daily-spend estimate, trips start one week from today.
